# Full-Stack Blog — Frontend

A Vue.js frontend for a full-stack blogging
application, integrated with a Java and
Spring Boot backend.

## Technologies
- Vue 3
- Vuetify
- JavaScript
- Vite
- REST APIs

## Getting Started

Install dependencies:

    npm install

Start the development server:

    npm run dev

Build for production:

    npm run build
